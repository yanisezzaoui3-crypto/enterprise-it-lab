# Environnement local de développement et outils IA

## Expérience déjà acquise

J'ai déjà installé, lancé et dépanné plusieurs outils de développement ou assistants IA depuis Windows.

Les manipulations ont notamment demandé de travailler avec :

- terminal et PowerShell ;
- Node.js et npm ;
- Bun ;
- variables d'environnement ;
- fichiers `.env` ;
- services locaux ;
- ports locaux ;
- logs d'erreur ;
- configuration de providers et modèles.

## Ce que j'ai appris

Installer un outil ne signifie pas seulement lancer un installateur.

Il faut souvent comprendre la chaîne :

```text
application
→ dépendances
→ configuration
→ variables d'environnement
→ service local
→ logs
→ diagnostic
```

## Compétence travaillée

Lire une erreur, identifier à quel niveau elle apparaît et vérifier chaque couche progressivement.
