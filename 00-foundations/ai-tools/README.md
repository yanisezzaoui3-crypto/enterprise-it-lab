# Outils IA dans mon environnement de travail

J'utilise plusieurs assistants et outils IA pour apprendre, développer, analyser et vérifier mon travail.

## Expérience déjà acquise

- utilisation d'assistants de code ;
- configuration d'outils IA locaux ;
- utilisation de fichiers de configuration et variables d'environnement ;
- lancement et dépannage d'outils depuis le terminal ;
- lecture de logs ;
- comparaison de réponses entre plusieurs outils ;
- utilisation de l'IA comme assistance plutôt que comme preuve automatique de maîtrise.

## Principe

Pour chaque projet assisté par IA, je cherche à pouvoir expliquer :

1. le problème ;
2. la solution proposée ;
3. ce que fait le code ou la commande ;
4. comment j'ai vérifié le résultat ;
5. ce que j'ai appris.

L'objectif est de transformer l'assistance IA en compétences techniques vérifiables.
