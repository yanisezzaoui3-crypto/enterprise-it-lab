# Windows et PowerShell — expérience déjà pratiquée

## Outils et manipulations

J'ai déjà utilisé Windows et PowerShell pour effectuer des vérifications et du diagnostic sur mon propre environnement de travail.

Exemples de sujets manipulés :

- navigation et exécution de commandes dans PowerShell ;
- processus Windows ;
- journaux d'événements Windows ;
- observation de processus avec Process Monitor ;
- vérification de services et logiciels installés ;
- observation de connexions et ports locaux ;
- dépannage d'installations et d'outils de développement.

## Objectif

Transformer ces manipulations ponctuelles en méthode de diagnostic reproductible :

**symptôme → hypothèse → vérification → résultat → documentation**.

Les commandes précises seront ajoutées ici uniquement après les avoir exécutées et comprises.
