# Méthode de diagnostic Windows

## Situation

Quand un ordinateur présente un comportement anormal, le but n'est pas de modifier beaucoup de choses au hasard. Il faut d'abord observer, formuler une hypothèse et vérifier.

## Méthode utilisée

1. Identifier le symptôme.
2. Vérifier les processus actifs.
3. Observer les journaux Windows.
4. Contrôler les logiciels ou services concernés.
5. Vérifier les connexions ou ports locaux si nécessaire.
6. Comparer les résultats avec le comportement attendu.
7. Documenter ce qui a été trouvé.

## Outils déjà utilisés

- Gestionnaire des tâches ;
- Observateur d'événements Windows ;
- Process Monitor ;
- PowerShell ;
- outils de diagnostic réseau ;
- journaux d'applications.

## Ce que j'ai appris

Un diagnostic efficace doit distinguer :

- un symptôme ;
- une preuve ;
- une hypothèse ;
- une conclusion.

Un événement ou un processus inhabituel n'est pas automatiquement la preuve d'une intrusion ou d'un problème de sécurité.
