# Process Monitor

## Outil

**Process Monitor** est un outil Sysinternals permettant d'observer en temps réel de nombreuses activités Windows.

## Manipulation déjà réalisée

Je l'ai utilisé pour observer le comportement de mon propre PC pendant une phase de diagnostic.

## Types d'activités observables

- accès aux fichiers ;
- registre Windows ;
- processus ;
- événements système associés aux applications.

## Ce que j'ai appris

La quantité d'événements affichée est très importante.

L'objectif n'est donc pas de considérer chaque ligne comme suspecte, mais de filtrer selon :

- le processus ;
- l'heure ;
- le type d'opération ;
- le chemin concerné ;
- le contexte du problème.

## Compétence travaillée

Passer d'une observation brute à une recherche ciblée.
